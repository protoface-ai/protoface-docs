Base URL:

```text
https://api.protoface.com/v1
```

Authenticate with a Protoface API key:

```http
Authorization: Bearer sk_live_...
```

Create and manage keys in the [Protoface dashboard](https://app.protoface.com).
Keys can be unrestricted or limited to specific scopes. Inference keys use
`runs:read` and `runs:write`.

## Conventions

- IDs are prefixed strings such as `run_...`, `sess_...`, and `av_...`.
- Timestamps are ISO-8601 UTC strings.
- List endpoints use cursor pagination with `limit` and `starting_after`.
- Error responses use the envelope described in [Errors](/reference/errors).
- `POST /v1/run/{model_id}`, `POST /v1/sessions`, and `POST /v1/videos` accept
  `Idempotency-Key`. Use any unique string up to 255 characters and reuse it
  only for the same request. Run and session retries replay the original
  response. Avatar video retries resume in-progress work or replay a completed
  result. After a timeout, failure, or cancellation, an avatar video retry may
  start a new generation.
