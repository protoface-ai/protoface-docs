Each starter below is a working project. Clone it, add your keys to the
environment file, and run. The
[protoface-quickstart](https://github.com/protoface-ai/protoface-quickstart)
repo indexes every integration.

More examples live at
[github.com/protoface-ai](https://github.com/protoface-ai).

## Don't see your platform?

Protoface works with any stack that can call the REST API and stream
audio. If yours is not listed, start from the
[LiveKit Agents](/guides/livekit-agents) guide as a reference
implementation, or use one of the SDKs to build your own integration.
