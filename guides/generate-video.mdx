---
title: "Generate a video"
description: "Generate a video with Seedance 2.5, including synchronized audio."
---

Text to video is a single request. In the example below, Seedance 2.5
generates eight seconds of 720p video with synchronized audio from a
text prompt.

```bash
curl -X POST https://api.protoface.com/v1/run/bytedance/seedance-2.5 \
  -H "Authorization: Bearer $PROTOFACE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "operation": "video.generate",
    "prompt": "A wide shot of a sailboat crossing a quiet bay at sunrise.",
    "duration": 8,
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "generate_audio": true
  }'
```

The request returns a run ID immediately. The clip lands on `video.url`
once `status` reaches `completed`.

```bash
curl https://api.protoface.com/v1/runs/run_... \
  -H "Authorization: Bearer $PROTOFACE_API_KEY"
```

```json
{
  "id": "run_...",
  "status": "completed",
  "video": {
    "url": "https://...",
    "content_type": "video/mp4",
    "file_name": "output.mp4"
  }
}
```

For lower-cost drafts, use a shorter `duration` or set `resolution` to
`480p`. Check [current model rates](https://protoface.com/pricing) for
pricing by duration and resolution.

Bodies are not portable between video models. Seedance 2.5 uses
`duration` and `resolution`, and requires `operation` to select
`video.generate`. MiniMax H3 uses `duration_seconds` and `quality`; its
[inference quickstart](/guides/model-inference) includes the full
generation sequence. Build each body from its
[request schema](/guides/models#request-schemas).
