Protoface is a cost-effective generative media inference platform, running
frontier models for video, images, speech, music, 3D assets, and realtime
avatars behind a single API key. Now with the cheapest
[Seedance 2.5 API](/guides/generate-video).

## Inference

Generating a video takes one call to start it and one to fetch the
result. In the example below, Seedance 2.5 generates eight seconds of
720p video with synchronized audio.

```bash
curl -X POST https://api.protoface.com/v1/run/bytedance/seedance-2.5 \
  -H "Authorization: Bearer $PROTOFACE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "operation": "video.generate",
    "prompt": "A wide shot of a sailboat crossing a quiet bay at sunrise.",
    "duration": 8,
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "generate_audio": true
  }'
```

The request returns a run ID immediately, and `GET /v1/runs/{id}` carries
the file once the run finishes.

```json
{
  "id": "run_...",
  "status": "completed",
  "video": {
    "url": "https://...",
    "content_type": "video/mp4",
    "file_name": "output.mp4"
  }
}
```

Every model follows this pattern. Only the body changes, and you build it
from the model's [catalog entry](/guides/models). The
[MiniMax H3 inference quickstart](/guides/model-inference) runs the full
sequence, with a separate [image-to-video example](/guides/image-to-video).

## Realtime

Protoface Realtime adds a realtime face to your voice agent, driven by
the audio it already produces. It works across languages and with any
pipeline, whether speech-to-speech or separate STT, LLM, and TTS. Use the
LiveKit or Pipecat plugin, another supported platform, or the REST API.
The [realtime quickstart](/quickstart) adds a live avatar to a LiveKit
agent.
